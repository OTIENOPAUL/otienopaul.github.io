EmailIntel, Zero-Budget Contact Discovery System

A Python/SQLite system that reads public company pages, learns each company's email naming pattern from evidence, and returns ranked contacts with an honest confidence score and a full audit trail. No paid APIs, no SMTP probing, no inflated "verified" claims.

EmailIntel

The problem

Both StayFlow's own client pipeline and hotel clients' corporate and group booking prospecting relied on manually hunting for the right contact at each target company, a slow and inconsistent process with no honest way to tell a confirmed email from a guess. Paid enrichment tools exist, but at zero-budget pricing in a Kenyan SME context, none were viable.

What I built

A full-stack discovery engine with a CLI, a natural-language query interface, a local web UI, and a password-locked Windows desktop app, all running on free, open-source tooling only.

Key outcomes

  • Cut manual prospect research to a single command, with one search per target segment, using an OpenStreetMap + web-search discovery layer (search/sweep) covering 18 industries, including hotels, SACCOs and real estate, across any number of Kenyan towns in one run.
  • Replaced guesswork with a graded, source-backed confidence score (Discovered / Inferred / Possible, scored up to 97/82/45) by designing a scoring model that only labels a result "Discovered" when the exact address is published on the company's own site, and stores the source URL for every result.
  • Made the scoring model self-correcting over time by building a feedback loop (outcome / calibrate) that logs real replies, deliveries and bounces, penalises patterns per domain that bounce, and retunes scoring weights after 200–300 logged sends.
  • Built in regulatory compliance from day one, aligned to Kenya's Data Protection Act (2019) by enforcing robots.txt, rate-limiting every crawl, tagging each contact with a purpose (job search vs. agency prospecting), and shipping one-command suppression and erasure (forget example.com).
  • Shipped a password-locked desktop build with zero paid infrastructure by packaging the Python core into a Windows app with an encrypted local vault (password + one-time recovery code) and a GitHub Actions pipeline that builds the .exe without needing a Windows machine.
  • Verified correctness before shipping, with 40 automated tests passing by writing an end-to-end test suite covering a simulated hotel-site crawl and mocked map searches.

How it works

Domain resolution → polite crawl of homepage, contact/about/team/careers pages and public PDFs (robots.txt respected, 24h cache) → extraction of emails, named people and job titles from HTML, PDFs and obfuscated formats → pattern learning from named-person matches (e.g. mary.wanjiku@ + "Mary Wanjiku" ⇒ first.last) → generation of inferred/possible addresses only where evidence supports it → syntax + DNS MX verification → everything stored with its sources and reasoning.

For small properties that only publish a Gmail address or a WhatsApp number, the system deliberately does not guess a domain email; it surfaces the real contact channel instead.
