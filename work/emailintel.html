EmailIntel: B2B Contact Discovery & Validation Engine

A zero-budget Python and SQLite system that finds business contacts and scores how much to trust each one.

The problem

Both StayFlow’s own client pipeline and hotel clients’ corporate-booking prospecting relied on manually hunting for the right contact at each target company. It was slow, inconsistent and gave no honest way to tell a confirmed email from a guess.

Paid enrichment tools exist, but at zero-budget pricing in a Kenyan SME context none were viable.

How I solved it

  1. Discovery layer: OpenStreetMap plus web search finds companies across 18 industries, including hotels, SACCOs and real estate, in any number of Kenyan towns in one run.
  2. Crawling: reads public company pages while enforcing robots.txt and rate-limiting every request.
  3. Pattern learning: infers each company’s email naming pattern from evidence, then validates the domain’s MX records.
  4. Confidence scoring: labels a result Discovered only when the exact address is published on the company’s own site, otherwise Inferred or Possible, and stores the source URL for every result.
  5. Feedback loop: logs replies, deliveries and bounces, penalises patterns that bounce, and recalibrates weights after 200–300 logged sends.
  6. Packaging and testing: a password-locked Windows app with an encrypted local vault, built by a GitHub Actions pipeline, and verified by 40 automated tests including a simulated hotel-site crawl.

The outcome

  • Project documentation: It describes a command-line contact-discovery workflow; time saved has not been measured.
  • Honest confidence scoring (Discovered, Inferred, Possible, scored up to 97, 82 and 45) replaces guesswork, with a source URL behind every result.
  • Privacy safeguards: The project describes robots.txt handling, purpose tagging, and suppression/erasure controls. These do not establish legal compliance.
  • Shipped with zero paid infrastructure, as a password-locked desktop build and test cases are described in the private repository; execution was not independently confirmed.
